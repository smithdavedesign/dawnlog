What did your agent do overnight?

One receipt per git branch, built from the Claude Code session logs already on your disk. Each says what the agent was asked, whether its last test run passed, how often it retried, which risky files it touched and what it left for you. Ranked worst first, with a merge, fix or kill suggestion.

Free and MIT. Runs on your machine, read-only and offline. No hooks to install, no account, nothing uploaded.

Why trust a receipt

  • Every claim cites its transcript line (· L6), so you can check it instead of trusting it.
  • Secrets are redacted in everything it prints or writes. That's best-effort, for 12 token formats.
  • It never says merge without a passing test run. A test piped into tail is UNVERIFIED, not PASSED.
