Privacy

Effective 13 October 2026. The short version: the tool keeps everything on your machine, this site sets no cookies and counts three kinds of event without knowing who you are, and Stripe handles payments.

The tool

overnight-receipts runs on your machine. It is read-only: it reads the Claude Code session logs in ~/.claude/projects and your git repositories, and it writes only the files you name with --out. Nothing is uploaded. There is no telemetry, no account and no update check. Without --summarize, the only program it runs is git, and it opens no network connection (its tests check this).

With --summarize, it runs your own claude command-line tool. That sends each receipt's facts and the agent's final message, secret-redacted first, to Anthropic, under your account and Anthropic's terms. Leave the option off and nothing is sent.

Redaction is best-effort. It covers 12 token formats in everything the tool prints or writes. A format it doesn't know will show, so review a file before you share it.

The license string in {{LICENSE_ENV}} is never checked, logged or sent anywhere.

This website

This site sets no cookies and uses no third-party analytics, trackers, fonts or scripts. Vercel hosts it and keeps standard request logs (IP address, browser, page, time) for a short period, under Vercel's privacy policy.

To see whether anyone uses it, the site sends one small message, a beacon, to RepoHQ (repohq.vercel.app), the maintainer's own project dashboard. It's sent for three events:

  • visit: you opened a page here. Sent once per browser session.
  • activate: you copied the install command. Sent once per browser.
  • checkout: you clicked the Buy button.

Each message holds only the product's name (dawnlog), the event, and the address of the page that linked you here, if that page was on another website (otherwise nothing). It carries no cookie and no identifier. Like any web request, it reaches RepoHQ's host with your IP address, which its request logs keep for a short period. To send each event only once, your browser keeps two small notes in its own storage (sessionStorage and localStorage). They aren't cookies and never leave your browser.

Nothing is sent from automated browsers that say they are one, from preview deployments, or from the page you see after paying. To turn it off in your browser, set repohq:notrack in this site's localStorage, for example in the browser console: localStorage.setItem('repohq:notrack', '1').

Buying Pro

When you buy, you're on Stripe's checkout page. Stripe collects your card details, email address and billing details under Stripe's privacy policy. Card details never reach the maintainer.

The maintainer sees what Stripe's dashboard shows for a payment: your name, email address, country, the amount and the checkout session id (your license string). This is used only to send receipts, handle refunds, resend a lost license string and answer you. It's never sold or shared, and it's kept only as long as tax and accounting rules require.

After paying, Stripe sends you to a thank-you page with the session id in its address. That page shows the id to you and sends it nowhere. The page isn't indexed by search engines, and its links pass no referrer.

Your choices and contact

Questions about this policy: open an issue on the project's GitHub repository. Issues are public, so don't post anything private there. To see or delete what's held about your purchase, reply to your Stripe receipt instead. Records that tax rules require are kept for as long as they require; everything else is deleted.
